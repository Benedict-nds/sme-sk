# SME skills

Five starter skills for the SME digitization project. Each folder holds one SKILL.md.

- house-rules: shared rules for every agent
- source-comparison: form CSV vs transcript and summary
- client-needs-brief: one-page brief per client
- need-triage: digital now / later / non-digital / not realistic
- check-against-client-notes: reviewer's checks

Import each folder into Paperclip (Skills, then My Skills), then enable the right skills on each agent.
